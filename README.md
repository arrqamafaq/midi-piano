

# Piano Simulator  

A highly interactive virtual piano application powered by JavaScript and the Web Audio API. This project features dynamic piano creation, where the piano layout, including keys and their functionalities, is generated programmatically based on note configuration data.

---


**Live Demo:** https://arrqamafaq.github.io/Piano-Simulator/


---

### Features  
- **Interactive Keyboard**: Play notes by pressing keys on your keyboard or clicking on the piano keys with your mouse.  
- **Realistic Sound**: Generates tones with harmonics and adjustable envelopes for a natural piano-like experience.  
- **Dynamic Piano Generation**: The piano layout is dynamically created based on the piano details stored in an object, making the application flexible and scalable for different piano configurations.  
- **Multi-Note Support**: Supports playing multiple keys simultaneously for chords.  
- **Customizable Design**: Easily update the UI to match your preferences.  
- **Lightweight and Accessible**: Runs directly in the browser without additional dependencies.
